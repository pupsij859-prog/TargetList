# TargetList
Сайт для своих целей и мечт

## Что находиться? 

- **Экран приветствия** — по Enter (или клику) переходит в приложение с плавным расфокусом фона
- **Два раздела** — «Цели» и «Мечты», переключаются вкладками (или клавишей `Tab`)
- **Мечты** — крупные «хочу»: к мечте привязываются цели, её прогресс = средний прогресс этих целей
  Когда закрыта последняя цель — мечта сбывается сама, с конфетти. Можно и отметить руками, если сбылась без плана
- **Два типа целей**
  - *чек-лист* — список шагов, прогресс = сколько отмечено;
  - *счётчик* — «прочитать 12 книг», кнопки − и + прямо на карточке.
- **Общий прогресс** — кольцо с градиентом: на вкладке целей считает среднее по целям, на вкладке мечт — насколько сбылись мечты.
- **Статистика** — в работе / закрыто / маленьких побед / дней подряд и столбики активности за 2 недели.
- **Дедлайны** — карточка сама пишет, сколько дней осталось, и краснеет, когда горит.
- **Фильтры** (все / активные / выполненные / горят), поиск и сортировка.
- **Анимации** — появление карточек, блик по прогресс-бару при наведении, конфетти при закрытии цели, тосты, мягкое свечение под курсором.
- **38 SVG-иконок и 8 цветов** на выбор для каждой цели — никаких эмодзи, всё рисуется вектором и тянет цвет из темы.
- **Экспорт/импорт** целей и мечт в JSON — внизу страницы.

## Горячие клавиши

| Клавиша | Что делает |
|---|---|
| `Enter` | войти с экрана приветствия |
| `N` | новая цель или мечта — смотря какая вкладка |
| `Tab` | переключить «Цели» / «Мечты» |
| `/` | фокус в поиск |
| `Ctrl` + `Enter` | сохранить цель в открытом окне |
| `Esc` | закрыть окно |
